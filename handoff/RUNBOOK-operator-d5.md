# 人工輪操作手冊 — E2-C D5 的四格

寫於 2026-08-16。**這一輪只做 D5 的四格。**

## 先講一件會影響你怎麼排時間的事

**E1-C 的收復這次不做**，而且不是排程問題。SPEC E1-C §11.8 的解除條件第 1 條是
「`e1-editor-v1` 的 relink 決定**作出之後**的第一個 operator 時段」——那個決定還沒
作出（它在等 v3 的參數化形式在產品上驗過，而 v3 的連結今天決定先等）。

現在做的話，若之後 `e1-editor-v1` 真的 relink，這兩輪人工**百分之百作廢**——
那正是 §11.8 當初把它延後的承重理由。**設置是一樣的，資格還沒到。**

## 為什麼這四格非要人不可

D5 整個相位的主題就是 `isTrusted`：瀏覽器會在每個事件上標記它是不是真人做的，
程式合成的一律是 `false`。我們的判定器**會據此拒絕**——這一點已經用機器那一半
證明過了（把補齊其他條件的那一格翻**一個**事件成合成，它就不過）。

所以這四格不是「還沒寫自動化」，是**自動化在定義上做不到**。

## 環境（四格都要，缺一格就少一格）

- **真的滑鼠**（拖曳選取要真的按住、移動、放開）
- **Fcitx5 新酷音**輸入法，能打中文並確定
- **真的剪貼簿**（系統剪貼簿，不是頁面內模擬）
- 瀏覽器**兩個都要跑一輪**：Chrome 與 Firefox

## 開始

```bash
cd /home/jiajun/LibreOffice/study_LiteCore/wasm_sdk_probe
python3 tools/run_e2_c_d5.py --serve --port 8791
```

它會印出網址。**在真的瀏覽器視窗裡打開**：

```
http://127.0.0.1:8791/e2-c-d5.html?profile=e2-editor-v2
```

頁面上半是產品編輯器（**原封不動**跑在同源 iframe 裡），下半是四格的按鈕。

## 四格，每一格都是「按開始 → 做動作 → 按做完」

| 格 | 你要做的事 |
|---|---|
| `d5-pointer-drag-single` | 用滑鼠在**同一段**文字上拖曳選取，放開，然後按工具列的「項目符號」 |
| `d5-pointer-drag-cross` | 同樣的動作，但**跨兩段** |
| `d5-ime-commit` | 用新酷音在游標處輸入一次中文並確定；再**選取一段文字後輸入一次取代它** |
| `d5-clipboard` | 用真的 Ctrl+C 複製一段文字，把游標移到別處，用真的 Ctrl+V 貼上 |

**順序不重要，做完一格再開下一格就好。** 每一格：先按「開始這一格」，做動作，
再按「這一格做完了」。中間頁面會即時印出收到幾個事件。

## 做完之後（兩個按鈕，都要按）

1. **「全部做完，送出證據」**
2. **「把證據存成一個檔案」** → 會下載一個 JSON（metrics ＋ 所有存下來的文件）

**把那個檔案的路徑給我就好，其他都不用收。** 這個匯出路徑不是寫完沒跑過的——
機器那一半每次都會實際呼叫它一次並把結果記進證據（`operatorExport`）。

## 會發生的事，先講在前面

- **某一格做壞了可以重做**：再按一次「開始這一格」會覆蓋那一格的紀錄。
- **不要按到會跳出瀏覽器對話框的東西**（例如任何 confirm／alert）——那會卡住
  整個頁面的事件。
- **頁面不會判定**，它只記錄。判定是我離線跑分析器做的，判準早就凍結了。
- 兩個瀏覽器各做一輪；哪一個先做都可以。

## 我在收到檔案之後會做的

```bash
python3 tools/analyze_e2_c_d5.py <operator run dir> --output verdict.json
```

四格全部成立才會從 `NOT_ESTABLISHED` 變成 PASS，而**那不是我可以幫你按的**——
這正是這一輪存在的理由。
