## 2. 新功能

### 2.1 在 Nextcloud 裡開、編輯試算表（`.ods`；0.2.29–0.2.38）

**唯讀檢視**

- Files 裡點 `.ods`，開在 LiteCore 的檢視頁，下方是工作表分頁，名字由引擎讀出。〔已觀察：`host-0.2.29/README.md`；擁有者親手點過，0.2.32「三個分頁都可以開啟」、0.2.33「三個工作表都能顯示」〕
- 現在的檢視引擎是 `ods-viewer-v3`。上游語料 306 份，三趟全語料都開 303 份、拒絕 3 份加密檔；v2 開得了的 298 份全部照舊過。〔已觀察：`specs/SPEC-M4-viewer-v3.md` §14–15〕
- 檢視是真的唯讀：不拿鎖、不寫回，ETag 與版本數不動。〔已觀察：`host-0.2.29/README.md` H2，含「偷拿鎖的宿主」紅案；0.2.33 上 `VIEWER HOST HOLDS`〕

**編輯（0.2.34 起）**

- 可寫的 `.ods` 從 Files 進編輯器：雙擊格子原地編輯，上方有寬的公式欄，粗體／斜體／底線，Enter 提交、Escape 取消，Ctrl／Cmd+S 存檔。走真的鎖、條件式 PUT 與衝突副本。〔已觀察：`host-0.2.34/README.md`，原生 171、瀏覽器 186、宿主每個瀏覽器 23＋2 項〕
- 唯讀分享的檔一律走檢視頁，沒有存檔入口、不拿鎖。這是實際分享才抓到的路由問題，0.2.34 修掉才出。〔已觀察：同上，`host-readonly-05`、`host-firefox-07`〕
- 0.2.36 起：選格後直接打字會取代內容，F2 進入編輯保留內容，滑鼠拖曳與 Shift 可以選矩形範圍。〔已觀察：`host-0.2.36/README.md`，鏡像 378/378、Files 28/28〕
- 0.2.37 起：多格 B／I／U，以及自動儲存。閒置 30 秒存已確認的修改；未存超過 5 分鐘時，等 3 秒沒有動作就存。〔已觀察：`host-0.2.37/README.md`，鏡像 240/240 與 108/108、Files 54/54〕
- 擁有者手測：文字與公式輸入、整格 B／I／U、雙擊進編輯都通過。〔已觀察：`specs/SPEC-M4-cell-editing-v1.md` §9、§12〕

### 2.2 貼上為 Markdown（0.2.27 起）

- 工具列「貼上為 Markdown…」開對話框，貼上文字按「插入」。轉出來的結構和桌面 Writer 相同，中日韓文字不亂碼，一次復原就回到貼上前。〔已觀察：M1 87 格、M2、M4 171 格，兩個瀏覽器，`RELEASE-TEXT-DRAFT-0.2.27-0.2.28.md` §2.1〕
- 含遠端圖片或 HTML、內容空白、超過 65,536 位元組，或有選取範圍：明確拒絕，文件不變，也不連線到裡面的網址。〔已觀察：同上，M3、M5〕
- 貼上之後約 30 秒自動存檔；擁有者在真的 Chrome 上確認過「插入」與「取消」之後打的字都進文件。〔已觀察：`host-0.2.27/README.md`；`host-0.2.33/f3-hand-2026-10-25/owner-confirmation.md`〕

### 2.3 Shift＋方向鍵、範圍上的方向鍵（0.2.40 起留下來）

- 擁有者點名要的功能。Shift＋←→↑↓、Shift＋Home／End 擴大或縮小選取；有選取時按一般方向鍵，落點和 Writer 一樣。〔已觀察：R1，見下〕它能出，是因為引擎換成單一順序的指令路線（3.3）。

### 2.4 Ctrl+A／Cmd+A 全選（0.2.42 起）

- 0.2.39 第一次帶上它、當天回退；0.2.40–0.2.44 都帶著。名義出貨版本 0.2.26 沒有這個問題。〔已觀察：finding 177 的版本表〕
