## Standing rules (carried, plus new)

- One runner at a time; native probe runs need a quiet machine; never `pkill -f` with a pattern matching your own command line.
- Never `rm -rf "$VAR/…"` — the harness refuses it; use literal paths or new directory names.
- The owner's `PMPC指南.odt` never enters the repository (read only from `wasm_sdk_probe/build/scratch-m3-production-ui/`); reports and evidence carry hashes and paragraph indexes, not paragraph text. Kept saves of it live under `wasm_sdk_probe/build/`.
- Typed-text documents compare by paragraph text, never bytes.
- `build_cutover_page.py --write` only at the cutover; candidate measurements use `--candidate-profile`.
- Anything packed into a profile is built deterministically (fontTools: `recalcTimestamp=False`) and verified table by table against what it replaces. (The base pack follows the same rule at slice level: V1 compares every kept slice by sha.)
- Never write into a mirror subdirectory (they are symlinks into `dist/`), only the mirror root.
- `findings/evidence/**` and `handoff/**` English; specs, research, findings' prose zh-TW; specs append-only (corrections go after, naming what they supersede).
- A predicted-before-the-run file is committed before the run; a miss is reported as a miss and the pre-written fallback is taken. Applied this stretch: W2 (§25), V4's "becomes 20" (left as a miss, §26.3 not edited), the corpus L2 "which documents move" (registered in RESULT.md).
- A candidate report is only evidence about the page it names; check `candidateSource` and `pageSha256` against `build_cutover_page.py --profile <profile>` before citing it. The page differs per profile.
- **New (a):** a relative `<include>` in a fontconfig file resolves against fontconfig's **default** configuration directory, not the including file's. Native reruns must include the pack's `conf.d` by absolute path and record which rule files were loaded; `tools/check_fontconfig_lang_rewrites.py` fails on any rule file from outside the pack, and its relative-include red case is the guard.
- **New (b):** before saying a pack "can carry" a file, read what the worker admits (`sdk/sdk-worker.js` `safeResourcePath`), not what the pack builder can write.
- **New (c):** a zero-band or `unsettled` read is "not measured", never "equal"; two empty lists compare equal and a criterion written on equality then holds vacuously. Report how many items were actually measured.
- **New (d):** review labels collide across documents. "N2" is used for three different things this day (10-07c's Firefox latency note; finding 114's review N2 about the weak default language channel; spec §26.3's N2 prediction that Latin rows do not move). Cite the document with the label.

## Lessons this stretch

- **An instrument reports only the half it is pointed at.** `strace` showed which font files were opened (7 vs 363) and could not show which rule files were loaded; "the config was in effect" was true of the fonts and false of the rules, and a whole conclusion ("the cause is on the WASM engine side") rested on that half.
- **A positive result can come from the wrong rules.** The census printed "0 rewrites" for v16 when the relative include was left in place, because the profile's rules were never loaded; only the extra "rule files loaded from outside the pack: 63" line shows it.
