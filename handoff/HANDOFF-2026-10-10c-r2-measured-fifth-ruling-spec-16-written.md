## Standing rules (new this stretch; a–qq stand)

- **(rr) Check a ruling's facts about the buyer's configuration before relaying them.** Fable's first text said Windows 150 % is ratio 2; it is `devicePixelRatio` 1.5 (backing 1350 px at the 900-px cap, ≈ 1,517 rows per page), so the page ceiling moved from 33 to 43 pages. Both corrections went back to fable before anything was acted on.
- **(ss) An instrument that counts bytes must count what the call copies.** The 7-argument `putImageData` copies only the dirty rectangle; the wrapper counted the whole source image until `9d7b9ffd`, which would have scored P's small restores as whole bands.
- **(tt) In Firefox measure per task, not per call.** The first `putImageData` (or a draw from a large source) into a large canvas in a task pays a cost set by the canvas size (≈ 22 ms at 1800 × 44,514, ≈ 6 ms at 900 × 22,257); a second one in the same task is ≈ 0. In the product the re-blits come 18–44 to a task at ≈ 0.6 ms each (README), the fresh bands one per task.
- **(uu) A null in a report is a finding until explained.** Three Chrome ratio-2 reports' `allCurrentAfterLastKeyMs = None` was finding 123 on the page, not the probe.
