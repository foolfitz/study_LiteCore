## Scorer and red cases

`--score` turns a report into per-arm PASS / FAIL / NOT_ESTABLISHED lines and a verdict `AUTOSAVE HOLDS` only if every arm in the plan has its count of PASS in both named browsers. `--red-cases` loads a shakedown report, applies one mutation per criterion to a deep copy and requires each to turn its arm red — at least: an auto record whose `conditions.composing` is true (AS-1); first auto at 300 s (AS-2); an auto record during keying (AS-2c); two copies (AS-4a/b); an `If` header on the copy PUT (AS-4c); a lost letter with no toast (AS-5 held); a stranded sha256 that is the first record's (AS-7); an O2 label read from a stranded save (O2-1 e); zero auto records (AS-1 → NOT_ESTABLISHED). Print each red case's line.
