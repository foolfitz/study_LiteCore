LiteCore 結構編輯標題與清單，跑在 discovery build 上 啟動中
這不是產品契約，是一個被量過的實驗檯。 標題與清單這五個動作在 — 上量過 （SPEC E2-A 的 A3／A4／A5，以及 A7 的 round-trip 與回歸，兩瀏覽器）。 E2-A 的總判定是 PARTIAL_GO_TO_E2_B（2026-08-14，帶七項縮限）—— 那句話的意思是「可以往 E2-B 走」，不是「這些動作已經進了出貨的 e1-editor-v1 契約」：E2-B 的 ABI 還沒凍結，所以它們仍然不在產品裡。 這個頁面釘死在上面那個 build： discovery 引擎一往前走，這裡就會拒絕啟動而不是跟著跑。
手勢是「點一下段落，再按按鈕」。拖曳選取一段之後派送格式動作 從來沒有被量過（縮限 7）；而做過一次格式動作之後，範圍選取會返回但選不到東西 （縮限 4）。這兩件事都還開著。

它釘死在證據所描述的那一版引擎。目前提供的 profile 是另一個 build， 所以它拒絕啟動——跟著跑會變成展示一個沒有任何證據描述的東西。
