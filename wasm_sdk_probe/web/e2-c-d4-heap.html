E2-C D4 追加 — WASM heap 到底量不量得到

D4 把「產品報不出 WASM heap」登記成預測，並因此開出一個 relink 佇列項。 這一頁去量那個前提：出貨的引擎在每個 stage 就會印 emscripten_get_heap_size()，出貨的 worker 在 debug 開著時會把它轉成 diagnostic 事件，而 createDocumentEngine 本來就 收 debug。因此這一頁不改任何 hash 綁定的檔案—— 它只是多傳一個選項、多訂一個事件。兩條臂：fresh（每輪新 session，D4 自己的形狀）與 shared（一顆引擎跑完全部文件，SDK 層， 不是產品 session）。判準寫在 findings/evidence/sdk-e2/e2-c-validation/d4/heap/PREDICTION.md。 這一頁不判定。
