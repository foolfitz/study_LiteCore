這個 demo 能做什麼、不能做什麼

整份 LibreOffice 文件引擎編譯成 WebAssembly，跑在瀏覽器的 Worker 裡。 畫面是引擎算出的點陣圖，編輯經由一組窄版契約送進引擎；ODT 由引擎自己存出，不是前端拼的。

支援

  • 點擊定位游標、真 IME 輸入（注音／組字）、Unicode 與 emoji
  • 滑鼠拖曳選取（跨行、跨段落），範圍由引擎回報而非前端推算
  • 左右字元移動、Shift 擴張選取
  • Backspace／Delete 雙向刪除
  • Enter 段落換行、Shift+Enter 軟換行
  • 粗體、斜體、底線、刪除線（明確開關，非切換猜測）
  • 復原（Undo）、純文字複製貼上
  • 存成 ODT，桌面版 LibreOffice 可直接開

本版不支援（刻意不做，不是壞掉）

  • 上下行移動、Home／End（行導覽，見 finding 018）
  • 重做（Redo）、選取控點
  • 在選取範圍上按 Backspace／Delete（會被明確拒絕，文件不受影響）
  • 段落樣式、清單、表格等結構編輯
  • DOCX、格式化剪貼簿內容
