## 修法方向

深度規則把扣在頁面上的也算進去（`deletesInFlight + heldDeletes.count >= HELD_DELETE_DEPTH`），放開後回到「最多再刪 2 字」。任務 10-14q。

## 教訓（登錄，不是規則）

141 的修法動了「同鍵第二下怎麼等」，而這件事在文字中間也成立；10-14o 的 K1／K2 只量了邊界與一個「文字中間連按（`repeat: false`）」的對照，沒有量「文字中間按住（`repeat: true`）」。抓到它的是開跑前補的 132-B 守衛。
