# 084 — a11y core 上，游標偶爾整整跳過一次 commit：文字進了文件，游標原地不動，等到**下一次** commit 才補上

| | |
|---|---|
| **狀態** | **已特徵化，未修**。是產品缺陷，不是 harness 的（本來以為是，被自己的儀器打掉） |
| **發現日** | 2026-08-26。這格檢查在 a11y 這條線上**從來沒跑到過**——finding 082 修好之後才第一次被量到 |
| **嚴重度** | **中**：文字不會掉，游標會停在錯的地方直到下一次輸入。使用者看到的是「我打的字跑到別的地方了」 |
| **可重現** | **a11y core 27 次 commit 掉 3 次（11%）；出貨那顆 core 42 次 commit 掉 0 次** |
| **是否上游** | **未定**，而且**不指認任何一層**：兩顆 core 差兩個 build 變因，一次量測 |

## 一句話

在 a11y core 上，某一次 commit 之後**游標不動**——文字確實進了文件（revision 有進），
但頁面畫游標所依據的位置停在原地，**輪詢滿 8 秒都不動**，直到下一次 commit 才一次補兩格。

## 數字

`caret-follows-the-text-you-type` 讀 `#sink` 的 `offsetLeft`，一輪三次 commit。
十九輪、兩顆 core、每一輪都落在同一組位置上：

| 輪數 | profile | 結果 | 每次 commit 之後的位置 | 差 |
|---|---|---|---|---|
| 多數 | 兩顆 core 皆有 | PASS | 163, **278**, 393, 509 | 115, 115, 116 |
| v10 r1 / v11 r2 | a11y | FAIL | 163, **163**, 393, 509 | **0, 230, 116** |
| v11 r5 | a11y | FAIL | 163, 278, **278**, 509 | 115, **0, 231** |

**只有其中一次讀數不一樣，而總和完全相同**——兩條路都收在 509，而補上的那一步是
115＋115。所以那一次 commit 的游標移動**沒有消失，是被延到下一次**。

| core | 量到的 commit 次數 | 掉的次數 |
|---|---|---|
| 出貨（`e2-editor-v8`） | **42** | **0** |
| a11y（`e2-editor-v10`／`v11`） | **27** | **3** |

## 分佈是雙峰的，所以它不是「慢」

把固定的 `time.sleep(1.2)` 換成**對判準本身輪詢**（8 秒上限）之後，等待時間進了紀錄：

```
正常：  settledAfterMs = 0 或 1      ← revision 一到，游標就已經對了
掉的：  settledAfterMs = 8013        ← 輪詢跑滿上限，始終沒動
```

**0 ms 或永不。**中間什麼都沒有。這不是延遲分佈，是**掉了一次更新**。

## 我第一個判斷是錯的，是自己的儀器打掉的

看到「總和相同、只有中間那次讀數落後」時，我的第一個判斷是
**harness 讀太早**——那支臂等 revision 之後睡固定 1.2 秒，而這格檢查自己的註解就寫著
它涵蓋的缺陷本來是個 race。

**換成輪詢之後它還是紅的，而且紅得更清楚：8013 ms。**
輪詢期間沒有再打任何字，所以「要等下一次 commit 才補上」的缺陷**無法被輪詢遮掉**——
這正是把 sleep 換成 poll 之前必須先問的那個問題。

儀器換對了兩件事：把一個沒有數字的間歇紅變成有數字的紅；並且把
「harness 讀太早」這個對手假說**排除掉**。

## 沒有量的（因此不指認）

- **為什麼只在 a11y core 上。**兩顆 core 差兩個 build 變因（`writer calc` ＋ accessibility
  對上 writer-only 無 accessibility），一次量測——findings 040 和 048 的規矩。
  42 對 0 很強，但它是**發生率**，不是機制。
- **掉的是哪一層的更新。**`#sink` 的位置由頁面依引擎的游標回呼擺放；沒有量到
  回呼有沒有到、到了頁面有沒有用。下一步就是問這個：在同一輪裡把引擎那側的游標
  狀態和 `#sink` 的位置一起錄下來，就能分出「回呼沒來」和「回呼來了頁面沒用」。
- **對使用者的實際樣子。**這是合成輸入；真鍵盤下是不是同一個形狀沒有量過（D5 的範圍）。
