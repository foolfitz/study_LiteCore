1. **SUMMARY and §4, "(open, settle, 16 Enters, 16 Backspaces, scroll)"** — P2-c never scrolls (`arm_p2c` has no scroll step; the click and End before the edits are drained and discarded). `NOT_ESTABLISHED` covers open, settle, Enter and Backspace. Supersedes the word "scroll" in both places.
2. **§3 C1, "`selectionType "none"` … 12 of 12"** — true as a record, but until this review no clause read it: `noSelectionAt500ms` read `selection.collapsed/rectangles`, which is the engine's TEXT_SELECTION callback cache (`appendEditorState`, `probe_engine.cpp:1263`), not the fresh `readSelection()` that only `selectionType` carries (`handleEditorGetState`). The clause now requires `selectionType == "none"` (review opus 1a; `c1_clauses`). The committed rounds satisfy it 12/12, so the verdict stands.
3. **§3 C1, "no reopen toast"** — ARMS says "no toast"; the clause was "no reopen toast among the page's last three toasts" (those three were the opens'). The clause is now `noToast`: nothing appended to the page's toasts from the key to the engine read. In the committed rounds nothing was appended after the key (the three listed toasts precede it), so the verdict stands.
4. **§3 P2 remove, "60 = `parts` 60"** — when no `pageRectangles` reply lands in the final 2 s wait, the runner's fallback wrote the rectangle **count** into `partsAt2s`. The last reply seen during the remove presses carried `parts` 60 (`remove.firstReplyWithTarget.parts`), so the number is right; the field's provenance was not. The fallback now keeps the reply's own `parts` (`at_2s`), and the judge no longer accepts a `null` parts.
5. **§4, the ±25 ms detector** — it does not identify a flush: review 6's own counterexample (a lone id 13, the click's `INVALIDATE_VISIBLE_CURSOR` 22 ms later) reads *flanked*; at 26–28 ms it would read *lone*. `NOT_ESTABLISHED` here means "no id 13 without an id 0–4 within ±25 ms on the worker's clock", which leans toward the less severe grade for finding 138. The two observed size changes had `INVALIDATE_TILES` and `INVALIDATE_VISIBLE_CURSOR` within the window; whether they shared a flush is not something this instrument can say.
6. **§3 E2, "equal in every instance"** — in all 12 instances the barrier-start cache, P and the cache at refusal are the same rectangle (key-deadline: K2 and Escape #2 return the caret before the request; anchor-mismatch: raised from the TEXT_SELECTION branch, before Writer's caret callback). E2's PASS establishes "caretBefore equals the caret before the key where every candidate definition coincides"; the class that would separate them is E3's, registered unreachable.
7. **Judge usage** — `--expect-page` is now required (without it: `VERDICT NOT GIVEN`, exit 1), and a second `report-*.json` for the same (browser, arm) FAILS that cell in either order; superseded reports belong under `witness/`, as §6 already does.
