## The ruling, verbatim

> **Ruling: B, with A as the declared fallback; C only if both fail.** The run-01 type saves measure the sequence "x, then Shift" in 56/56 cells; the declared cell is "Shift, then x". A save of a different input sequence is not an oracle for this one, whatever its provenance. The NOTE's premise (line 23: same queue ⇒ same processing order) is measured false and is withdrawn (§4), not patched by reinterpretation. B is the right repair because the product's claim is a Writer-parity claim ("typing over a Shift extension replaces it as Writer does"); a WASM-vs-WASM reference (A) can only witness self-consistency, so it is the fallback, not the first choice. C throws away an obtainable oracle.
>
> **Exact oracle for the type family (56 native-capable cells; Up/Down 28 stay settled-WASM; Home/End still conditional on the browser single-line witness).** Native run-02, type cells only, fresh document per cell: setup as run-01 → Shift key INPUT/UP → the harness's existing bounded settle (800 ms quiet / 8000 ms cap) → native selection read → char 120/key 0 INPUT/UP → settle → after-save. Comparator unchanged: paragraph text (`paragraph_texts_from_xml`) of the candidate's after-save equals the run-02 after-save.
> **Required per-cell order witness (else that cell's native oracle is NE, never "assumed ordered"):** (i) posts recorded in declared order; (ii) the between-read's selection text equals all three `nativeAfterSelectionText` rounds for the member, and the read's completion timestamp precedes the x post timestamp; (iii) a cap result or missing between-read is NE, no retry until green. > **Plain-language rationale for the owner.** The native reference was supposed to answer "what does Writer do if you extend a selection with Shift and then type x" — but the harness delivered the x to Writer before the Shift, so in all 56 cases it answered the opposite question, and the product was being failed for doing what a user would actually see. If a cell cannot be proven ordered, it falls back to comparing the product with its own settled run, which is weaker and is labelled as such.
