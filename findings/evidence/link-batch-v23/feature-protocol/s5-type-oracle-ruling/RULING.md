## The ruling, verbatim

> **Ruling: B, with A as the declared fallback; C only if both fail.** The run-01 type saves measure the sequence "x, then Shift" in 56/56 cells; the declared cell is "Shift, then x". A save of a different input sequence is not an oracle for this one, whatever its provenance. The NOTE's premise (line 23: same queue ⇒ same processing order) is measured false and is withdrawn (§4), not patched by reinterpretation. B is the right repair because the product's claim is a Writer-parity claim ("typing over a Shift extension replaces it as Writer does"); a WASM-vs-WASM reference (A) can only witness self-consistency, so it is the fallback, not the first choice. C throws away an obtainable oracle.
>
> **Exact oracle for the type family (56 native-capable cells; Up/Down 28 stay settled-WASM; Home/End still conditional on the browser single-line witness).** Native run-02, type cells only, fresh document per cell: setup as run-01 → Shift key INPUT/UP → the harness's existing bounded settle (800 ms quiet / 8000 ms cap) → native selection read → char 120/key 0 INPUT/UP → settle → after-save. The candidate's timed sequence is unchanged (no inserted wait); this is the reference-side settle that ruling-3 line 55 already prescribes for settled references, applied on the native side. Comparator unchanged: paragraph text (`paragraph_texts_from_xml`) of the candidate's after-save equals the run-02 after-save.
> **Required per-cell order witness (else that cell's native oracle is NE, never "assumed ordered"):** (i) posts recorded in declared order; (ii) the between-read's selection text equals all three `nativeAfterSelectionText` rounds for the member, and the read's completion timestamp precedes the x post timestamp; (iii) a cap result or missing between-read is NE, no retry until green. For the members whose Shift snapshot is empty (the silent members), (ii) can only witness "settled, collapsed, caret at the moving point"; record `orderWitness: settle-only` for them — a weaker, named witness, not NE and not silently equal to the strong one. §6 red cases for the reader: swap the between-read and x timestamps → NE; replace the between-read text with the post-x selection → NE; feed a run-01 type record → NE (no between-read), which is also the proof that the old saves cannot slip back in. Do not pre-write expected after-texts; the after-save is the oracle, the between-state is the witness.
> **Fallback A trigger:** if run-02 cannot produce witness (ii) for a cell (for example the settle itself does not hold the Shift state), that cell uses the fresh settled-WASM reference under the existing rule; the reason is recorded per cell. Do not mix: a cell is native-referenced with witness, or settled-WASM, never native-without-witness.
>
> **The existing 56 run-01 type saves:** retained unchanged in run-01 (append-only evidence); not an oracle for any declared cell. Append to `s5-native/run-01.README.md` and to `reader-01.json`'s consumer notes that the type entries' status is "recorded x-then-Shift; not an oracle for the declared sequence"; the deletion entries keep `NATIVE_S5_SAVES_AVAILABLE`. > **Plain-language rationale for the owner.** The native reference was supposed to answer "what does Writer do if you extend a selection with Shift and then type x" — but the harness delivered the x to Writer before the Shift, so in all 56 cases it answered the opposite question, and the product was being failed for doing what a user would actually see. If a cell cannot be proven ordered, it falls back to comparing the product with its own settled run, which is weaker and is labelled as such.

Run 02 stays preserved, superseded, bound nowhere.
>
> Clause (iii) "no retry until green" stands. It forbids re-rolling a witness that can fail on the subject's behaviour. It does not forbid one re-run after an instrument repair when all five hold, and all five hold here: (a) the defect is in the instrument, independent of Writer, and shown from the preserved run's own record (between-text equals the rounds in 46/46 NE cells; only the printed timestamps collide); (b) the fix is one named line forced by run 02 (§9 condition 2) and enforced by the bound-source test; (c) the whole population re-ran in a fresh directory, not the failing subset; (d) the superseded run and its reading are kept; (e) the ruling authority acknowledges before anything counts — this addendum.
