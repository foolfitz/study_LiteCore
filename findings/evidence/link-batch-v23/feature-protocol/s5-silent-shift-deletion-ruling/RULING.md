> ## Plain-language rationale for the owner (fable)
>
> Writer has a quirk: press Shift+End when the cursor is already at the end of the line (nothing visibly happens), then Backspace — Writer swallows that Backspace and deletes nothing; only the second one works. Internally it kept an invisible zero-width "selection" and spent the first keypress deleting it. Our editor deletes a character on the first Backspace, which is what a user expects and what nearly every other editor does. The test was failing our editor for not copying the quirk. The quirk cannot even be seen through the interface our editor uses to ask Writer "is anything selected?", so copying it would mean inventing a hidden tracker — more machinery, worse product. Decision: these cells (about 49 of 588, decided one by one by a measured witness, not by a hand-written list — the hand list turned out to be wrong for five cells) are no longer compared to Writer's save; they are compared to our own settled run, and every such cell is labelled so nobody mistakes it for Writer parity. The failed run stays on record as the reason. The next counted run starts fresh after a 40-minute native witness run and a handful of tests that prove the new rule cannot be applied to the wrong cells. The quirk becomes upstream finding 167, to be confirmed on desktop Writer before anyone reports it.
