# FORMAT selection-mode restoration: predeclared native cohort

This new finite cohort is forced by the original 45-process RESET cohort's failing next-selection locator and by finding 049's independently documented SelectText residue. It does not alter the old cohort, its reader, its population, or its result. It is registered before any counted execution. **Unperformed, incomplete, unclean, or nondiscriminating evidence cannot authorize adoption.**

The executable population is generated by `F_ARMS` in `arms.py`: **eight arms × exactly five rounds = 40 fresh processes**, all in `unipoll`, accessibility disabled. This measures the concrete ordinary-text selection-mode counterexample, using only the existing `plain3` fixture and P2 start. It is not a new product/K population, nor a claim about all format commands, HTML correctness, empty paragraphs, cross-paragraph formatting, object selections, or extended/additive/block modes.

## Measured operations

The shared immutable harness fork is `../tool/oc_native.cpp`. Its `Q<point>` is a synchronous RESET→START→RESET at the same recorded caret coordinate. Its `E<point>` is synchronous `setTextSelection(END)` at the recorded coordinate. These are candidate measurement operations; their existence does not establish that restoration works.

Setup records P1 start (`wrong`), P2 start (`before`), and P2 end (`end`), then returns to P2 start. The reader requires P2 below P1, and end right of before on the same line. Every arm applies the same `StyleApply` with `Style=Text body`, `FamilyName=ParagraphStyles`, listener enabled. The four variants are:

- **direct:** only that format setter; no barrier-created selection;
- **reset:** format setter → RESET(before) → SelectText → RESET(before), the known-residue negative control;
- **candidate:** format setter → RESET(before) → SelectText → Q(before);
- **wrong:** format setter → RESET(before) → SelectText → Q(wrong), the wrong-location negative control.

All operations in that measured sequence run in one unipoll command without a settle between them. Each operation records its synchronous selection and undo readback. SelectText must return TEXT identifying the fixture's P2; restoration must return NONE. HTML is intentionally not read: this cohort isolates selection-mode restoration and does not establish the format HTML postcondition.

Each variant has two continuation arms:

- **shift:** save, then the existing final locator performs real Shift+End and Shift+Home. The direct locator must identify P2 exactly; the candidate must match it. The first Shift+End is the observed residue discriminator.
- **handles:** append RESET(point) → END(end) → RESET(point) in the same measured command, using `before` except `wrong` uses `wrong`. The END at-return read must select exactly P2 in the direct and candidate arms. There is deliberately no START rescue in this continuation. Save and run the final locator afterward. In the RESET-only control, END can itself heal the mode after failing to select; therefore its END read, rather than its later locator, is the discriminator.

## Fixed verdict

The reader derives every required cell and exact operation sequence from `F_ARMS`, checks the saved arm table and binary/source/fixture hashes, and requires precisely one successful run-log entry and one required output record per cell. The inherited `read_cell` checks actual saved output, native unipoll initialization, environment, completed process and uncapped settle. No a11y state may be enabled.

For each continuation and every round:

1. The direct next-selection witness is exactly P2 text, read from the immutable fixture. Its saved shape plus locator is stable across all five rounds.
2. The candidate's independently parsed saved shape, final locator, and next-selection witness equal direct. Its final undo-top comment equals the nonempty direct format undo-top comment. No timestamp equality is demanded across processes.
3. RESET-only and wrong-point controls each differ from the direct next-selection witness. A nondiscriminating control gives `NOT_ESTABLISHED`, never a pass.
4. SelectText establishes the intended P2 selection and the restoration returns NONE. Missing/wrong SelectText setup means no valid counterexample was exercised; a non-NONE restoration is a failed candidate observation.

All 40 clean cells meeting the conditions produce `FORMAT-RESTORE-HOLDS`. A clean observed candidate mismatch produces `FORMAT-RESTORE-FAILS`, provided the population and controls are established. Missing, unclean, unstable or nondiscriminating evidence produces `NOT_ESTABLISHED`. Both non-pass verdicts prohibit adoption. The reader exits zero only for HOLDS. A HOLDS result establishes this bounded restoration mechanism only; it does not close the later diagnostic browser FORMAT gates or the named content-identity limitation.

The cohort closes after its fixed five rounds. New concerns become findings or a separately registered follow-up; they do not silently expand this population or rewrite its counts.
