# Held-input defects: retained release and actual adapter admission

Independent Astra review found a plain/Shift modifier transition can replace the hold lookup while an earlier retained repeat still references the old hold. Releasing the physical key then missed that old record and dispatched its repeat after release. The fix includes the actual retained hold in keyup/blur traversal and deletes a map entry only if it still names that record. Both modifier directions and Shift keyup have causal cases; genuine nonrepeat initial presses remain admitted.

Source-faithful integration also found that the existing beforeEnqueue hook is later than input-adapter admission. Composition updates do not release it; the original frozen adapter remains the sole text submitter. The independent paste event is covered even when no beforeinput occurs. No generic queue, fixed wait, clipboard read or extra text commit was added.
