# Initial summary source disposition

The initial `cohort-summary.json` generator was an inline Python command and was not saved as a source file before the path comparison was corrected. The exact initial generator bytes are therefore unavailable in this evidence directory; no reconstructed file is presented as the original. Its output is retained unchanged as `cohort-summary-initial-path-check.json`, including the single false storage mismatch caused by comparing cohort-local runner paths to evidence-rooted index paths without the `counted-05/` prefix. The corrected mapping is reproducible from `correct_storage_path_check.py`; `storage-index-exactness.json` independently derives all 32 expected paths from `report.json`, checks unique membership, each raw SHA, stable index bytes, and the separate pack/verify exit receipts.
