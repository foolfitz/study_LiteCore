## Rulings S3 and S4 (shakedown README §1, commit `4574b8c4`), implemented 2026-10-17

- **S3, M5 (judge only; the runner already recorded host, port, time, window and both controls).** A cell fails only on a request or connection attempt to one of the item's targets: every `scheme://host:port` in its bytes (`originsNamed`, the scheme's port when none is written; `127.0.0.1`, `localhost` and `::1` are one host), plus any connection at the target-port listeners (listener, tarpit, closer). An item with no URL (X08, H1) has no target: its cell is its refusal. Every other non-mirror request goes into `M5.info` with its round, item, route, window, host and port, and the judge prints it as an info line, never a verdict. Both controls are required per round: the `probe.wasm` GET in the proxy's log, and `/m5-control` in the proxy's log and at the listener. On the smoke: M5 reads PASS (38 cells), with 17 Chrome requests recorded as info [observed].
