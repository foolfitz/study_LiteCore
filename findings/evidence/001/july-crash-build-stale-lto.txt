Reading: the four liblocaledata_*.a archives in the crash tree held LLVM bitcode compiled while --enable-lto was configured; after the reconfigure gbuild did not rebuild them (it does not track compiler flags), so the final link mixed LTO bitcode with non-LTO objects and wasm-ld reported 10262 signature mismatches. The July t3 'control' was a fresh directory without these objects, so it differed from the crash build in this respect as well as in --enable-symbols. NOT VERIFIED causally (the mixed state was not re-created on purpose); supported by: all five clean builds on 2026-11-10, including an exact replica at 671c848b, start normally.
