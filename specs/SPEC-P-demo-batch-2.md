# SPEC P：demo 批次 2——儲存與關閉的位置

> **狀態**：判準釘死，2026-11-02，寫在實作與量測之前。
> **來源**：擁有者 2026-11-02：「writer 跟 calc 的『儲存』跟『關閉』按鈕的位置差很多，請仿照 collabora 的方式設計」，附三張截圖。
> **不動**：引擎、連結、manifest、第 84 代的頁面程式（`e2-editor-app.js`）。本批做完是未計數候選 0.2.48，名義出貨版維持 0.2.45。

## 1. 現況

| | Writer | Calc | Collabora |
|---|---|---|---|
| 關閉 | 標題列最右 | 緊貼檔名（標題列沒有 spacer） | 最上排最右 |
| 儲存 | 工具列最右，藍色方塊 | 工具列最左，綠色文字鈕 | 工具列最左，一般圖示 |

檢視頁的關閉本來就靠右（`viewer.php` 的 `margin-left: auto`）。

擁有者的 Writer 截圖另有一件事：深色主題下工具列圖示淡到像停用，Calc 的 B、I、U 是深色方塊。成因是頁面沒有寫死按鈕文字色（Calc 連背景也沒有），Nextcloud 深色主題的 `button` 規則蓋過去。儲存改成一般圖示之後同樣受影響，所以一併處理工具列這一排。

## 2. 設計

- **關閉**：Writer、Calc、檢視頁都在標題列最右，右側間距相同。
- **儲存**：Writer、Calc 都是工具列第一個控制項，同一個磁片圖示、同一個大小，沒有底色，和其他圖示同一級，後面接一條分隔線。不再用藍色方塊、綠色文字鈕。
- **工具列顏色**：Writer、Calc 工具列的文字與圖示色寫死成頁面自己的 `--ink`，Calc 工具列按鈕背景透明，不隨 Nextcloud 主題變。工具列之外不動。
- Writer 工具列尾端留給縮放。

**陷阱**：宿主用 `#toolbar > .sep:nth-of-type(1)`、`(3)`、`(5)` 藏分隔線。`nth-of-type` 依元素類型計數，新分隔線如果是第一個 `span` 又帶 `.sep`，會被藏掉。所以用另一個類別名，div 的順序不動。

## 3. 判準

都在宿主上，真滑鼠；同一瀏覽器、同一視窗比 Writer 與 Calc。

| 判準 | 內容 | 形式 |
|---|---|---|
| T1 | 關閉鈕的右側間距在三個頁面上差 ≦ 1 px，都在標題列內 | 一 |
| T2 | 儲存鈕在 Writer、Calc 都是工具列第一個可見控制項，左側間距與大小差 ≦ 1 px，圖示相同，無障礙名稱含「儲存」 | 一 |
| T3 | 真滑鼠按儲存，存檔真的完成（宿主的儲存紀錄增加）；真滑鼠按關閉，回到 Files | 一 |
| T4 | 深色主題（Chrome 模擬）：儲存與粗體的文字色對工具列背景的對比 ≧ 4.5，Writer、Calc 都是 | 一 |
| T5 | Writer 儲存之後緊接一條看得見的分隔線 | 一 |

**紅案**：先在現行 0.2.47 跑。T1 要紅在 Calc，T2 要紅在 Writer，T4 要紅在 Writer。紅不出來就是工具沒量到症狀。

**回歸**：`web/e2-editor.html` 變了，F4、F3、V0′ 在新 HTML 上重跑，Z 也重跑；Calc 頁面跑 C、宿主 Files 實流程與 `host_batch.py`。`e2-editor-app.js` 不變，第 84 代的 digest 不變。

**沒做的預設**：維持現狀。

## 4. 具名限制

- **L-toolbar-only-theme**：只處理工具列。Calc 公式列的輸入框與按鈕在深色主題下仍是 Nextcloud 的深色。
- **L-close-host-style**：關閉鈕的外觀仍是 Nextcloud 的按鈕樣式，只改位置，不像 Collabora 是無框圖示。
- **L-save-no-dirty-color**：儲存不再有強調色，有沒有未儲存的修改看標題列的「尚未儲存」。
