## 2. 事實

### 2.1 機制（讀原始碼；`web/e2-editor-app.js` 指 `d761f1ce…`）

- **每一下刪除是一個排隊的引擎動作**：`beforeinput` 的刪除監聽器（`:2315-2326`）→ `editorAction`（`:1854-1885`）→ `run()`（`:1737-1747`）→ session 的單一 FIFO 佇列（`editor-shell/editor-session.js:262-266` 直接 `push`，沒有上限）。動作一個接一個進 Worker。
- **`run()` 等重畫**：動作回來之後 `changes += 1`、改延遲列、`await renderDocument()`（`:1746`）。重畫一輪問視窗裡過期的條（`:1195-1244`），每條回來就貼。
- **一輪被下一鍵中斷**：一輪進行中，下一個會到引擎的 `beforeinput` 設 `renderAgain`（`endRenderPassOnInput`，`:2354-2357`），下一個動作回來時 `run()` 也設它（`:1153`）；一條回來之後看到 `renderAgain` 就結束這一輪（`:1200`），下一輪從頭開始。
- **條的順序**：`bandOrder`（`:1122-1131`）把和視窗重疊的條排最前（距離 0），平手照文件順序。所以每一輪的第一條永遠是視窗最上面那一條；游標若在第二條，連按期間那一條輪不到（128 README 的 H2，SPEC-M3-autosave §9.15）。
- **重畫碰到 barrier 就放棄**：刪除的 barrier 在途時引擎對每個指令回 `BUSY`；有動作在外（`engineActionsOut > 0`）時重畫放棄、等動作回來的 `run()` 再畫（finding 128 的處方 B，`:1266-1269`）。
- **藍色**：barrier 刪除之前先選取那一個字，引擎把這次 TEXT_SELECTION 照常當 `editor-state` 送出（`probe_engine.cpp:2648`，finding 131 的同一個機制）；頁面的 `paint()`（`:1366-1399`）照引擎的狀態畫，範圍用淺藍 `#b7d3f2` 的 multiply 填色（`drawOverlay`，`:1476-1485`），範圍期間不畫游標（`overlayShapes`，`:1461-1469`）。
- **先例**：按住的 Ctrl+S 已經用 `event.repeat` 收成一次（finding 106，`:2417-2420`）。

### 2.2 底線（已觀察，`findings/evidence/132/baseline/README.md`，`7f58d53a`）

頁面 `d761f1ce…`、宿主 0.2.14、擁有者文件。按住照擁有者桌面的設定（GNOME `delay` 500 ms、`repeat-interval` 30 ms，讀進報告）：0 ms 按下、500 ms 起每 30 ms 一個重複、2000 ms 為止共 52 個 keydown、2015 ms 放開；重複都帶 `repeat: true`（兩個瀏覽器都讀回 51/52）。游標在視窗第一條（high）與第二條（low），兩個瀏覽器各兩次，共 8 次。

- **每一下的成本**：單按約 44–50 ms（keydown 到做完）；排隊時每一下約 66 ms（Chrome 中位數 65.6、Firefox 66.5）——多的是 `run()` 在兩下之間等的那一次重畫。
- **尾巴（132）兩個位置都一樣**：放開時引擎只做完 23–25 下，放開之後再刪 27–29 下，最後一下在放開後 1.79–1.86 秒。52 下全刪、沒有拒絕、`persistent` 0。
- **畫面凍住（L-128-rapid）只在 low**：游標那一條整串只重畫 1 次（第一下），放開時畫面顯示 1 下（引擎已做 23–25 下），其餘在放開後約 1.8 秒一口氣出現。high 每一下都重畫那一條（放開前 24–26 次），畫面跟著引擎、但引擎落後按鍵。
- **藍色殘影＝barrier 的選取被畫出來**：每一下刪除（單按或按住）都畫一次一個字大小的選取（例 `[562, 254, 13, 29]`），7–11 ms 後換成游標；約一半落在有呈現的畫格上（每次按住 52 次中 9–33 次）。§9.18 第 2 項的讀碼假說，量到了。
- 擁有者「上半下半感受不出區別」與尾巴一致：兩個位置放開之後都還刪 1.8 秒。§9.18 主 session 的假說「感覺到的是佇列，不是帶序」只對一半——兩半都在，只是 high 只有佇列。

## 3. 設計（擁有者 2026-10-12 選 A，第 4 節）

三個改動，各自獨立、各自有判準。都只動 `web/e2-editor-app.js`。

### 3.1 H1：游標那一條先畫

- **選擇**：`bandOrder(bands, visible, caretRows = null)`：和視窗重疊（距離 0）的條裡，和游標列重疊的排最前；其餘照舊（距離、平手照文件順序）。`renderDocument` 傳入 `caretDocRows()`＝引擎狀態的游標矩形換成文件列 `[floor(y·s), ceil((y+h)·s)]`，`s = docRows / heightTwips`；沒有游標回 `null`。
- **理由**：每一輪的第一條是唯一一定畫得到的那一條（下一鍵一到就中斷，§2.1）；使用者看的是游標那一行。
- **不做**：游標不在視窗裡時不讓它插隊（使用者在看的是視窗）。122 的其餘性質不動（視窗內先畫、由近而遠、中斷、每條一到就貼）。
- **重開**：122-U B2（「視窗內的條照文件順序」只在沒有游標、或游標在第一條時成立）。

### 3.2 H2：按住的鍵不超前引擎

- **選擇**：sink 上加一個 `keydown` 監聽：`dropsHeldRepeat(event, deletesInFlight)` 為真就 `preventDefault()`（這一下不會有 `beforeinput`、不送出）。為真的條件：`event.repeat === true`、`!event.isComposing`、鍵是 `Backspace` 或 `Delete`、而且頁面自己送出未結算的刪除 `deletesInFlight >= HELD_DELETE_DEPTH`（＝2）。
- **理由**：鍵盤每 30 ms 一下、引擎每 66 ms 一下，按住期間刪的速度由引擎決定，跟丟不丟無關；丟掉的只是放開之後的尾巴。深度 2＝一個在引擎裡、一個排著，所以引擎不會停下來等下一個重複，放開之後最多再做完這兩個。
- **不丟按下**：`repeat === false` 的永遠送出（連按的每一下都是按下，finding 131 的 131-B 守著）。
- **先例**：finding 106 的 Ctrl+S（`:2417-2420`）。
- **不做**：
  - 合併重畫（`run()` 不等重畫）：每下約 66 → 46 ms，仍跟不上 30 ms，尾巴只縮短一半、按越久越長，而且按住期間畫面不動（擁有者看過推算，沒選，第 4 節 B）。
  - 引擎一次刪多個字：要改引擎、要連結，屬於連結批次（`handoff/PLAN-2026-10-12-link-batch-shift-selection-and-page-number.md`）。
  - 用 session 的 `pending` 判深度：它也算存檔等別的動作；頁面自己的刪除計數是規則 A 已經在用的那一個。

### 3.3 H3：刪除在途時不畫引擎的範圍

- **選擇**：`overlayShapes()` 改讀 `overlayEditorState()`：引擎狀態若是範圍（`selection.collapsed === false`）而且頁面有刪除在途（`deletesInFlight > 0`），就沿用上一份畫過的狀態，不換；否則換成引擎的狀態。刪除監聽器在計數回到 0 時呼叫一次 `paint()`（在途期間到達的真範圍不會漏畫）。
- **理由**：和規則 A 同一個推理（SPEC-M3-autosave §9.12）：刪除在途時引擎的範圍是 barrier 選的那一個字，不是使用者的；它回來時只可能是游標。沿用上一份（而不是改畫引擎此刻的游標）是刻意的：barrier 期間引擎的游標可能已經在那個字的左邊，提早畫過去會讓 128 量的「游標動了、字還在」變長。
- **不做**：在引擎抑制那一次 TEXT_SELECTION（要連結）；格式動作的 barrier（finding 083 的 `.uno:SelectText`）也會選字，規則 A 刻意只管刪除，這裡也只管刪除（具名限制 L-132-format-flash）。

## 8. 具名限制（新登錄）

- **L-132-rate**：按住 Backspace／Delete 刪的速度是引擎的速度，約每秒 15 字（每下約 66 ms），不是鍵盤的每秒 33 下；按住 2 秒約 25 字。要更快得讓引擎一次刪多個字（連結批次）。

- **L-132-format-flash**：格式動作（粗體等）的 barrier 也會選字；那一瞬間的範圍照畫（未量）。
- **L-132-typing-hold**：按住一個字母鍵（插入）不在這一輪；未量。
