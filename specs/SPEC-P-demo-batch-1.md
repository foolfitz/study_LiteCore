## 2. Calc：每張表記住自己的視圖

參考：Collabora `browser/src/layer/tile/SheetSwitch.ts`，看過的表還原位置，沒看過的表捲到該表的游標。未複製程式碼。

**行為**：

- 離開一張表時記下它的捲動位置與作用儲存格（編輯頁）；檢視頁沒有儲存格，只記捲動位置。
- 切到**看過**的表：回到離開時的捲動位置與作用儲存格。
- 切到**沒看過**的表：從頂端開始，作用儲存格 A1。
- 記憶只活在這次開檔內。

**只還原捲軸不夠**：`showPart` 把作用儲存格設回 A1，畫面留在第二頁、游標卻在 A1，下一個方向鍵就跳回頂端。所以作用儲存格一起記。

**判準**：真瀏覽器、真滑鼠點分頁、真滾輪、真方向鍵；Chrome＋Firefox；每瀏覽器一輪。夾具三張表（列數不同，第三張很短，讓還原位置時能抓到「先捲再撐開內容」的錯誤順序）。

| 判準 | 內容 | 形式 |
|---|---|---|
| C1 | 每一次切到沒看過的表：`scrollTop`＝`scrollLeft`＝0，作用儲存格 A1 | 一 |
| C2 | 每一次切回看過的表：`scrollTop`、`scrollLeft`、作用儲存格都等於離開時的值，容差 0 | 一 |
| C3 | 每一次切換之後：頁面的 part 等於點的分頁，視窗範圍內有該 part 這次畫的 tile，tile 不是空白 | 一 |
| C4 | 切回之後按方向鍵：作用儲存格從還原的格子走一步，捲軸不跳回頂端 | 一 |
| C5 | 在還原的格子打字並存檔：存檔裡只有那張表的那一格變了 | 一 |

C1–C3 同時跑編輯頁與檢視頁，C4、C5 只跑編輯頁。

**紅案**：實作之前先在現行頁面跑，編輯頁的 C1 要紅，而且紅的樣子要等於擁有者的症狀（tab2 的 `scrollTop` 不是 0）。這一輪紅不出來，就是工具沒量到症狀，先修工具。

**沒做的預設**：維持現行行為，發佈說明列為已知問題。

## 3. Writer 縮放

參考：Collabora 的工具列縮放（`browser/src/map/Map.js` 的縮放等級），由 core 重畫，不是拉伸點陣圖。未複製程式碼。

**行為**：

- 工具列尾端、儲存按鈕之前：`−`、目前百分比、`+`。放在工具列，是因為宿主藏了 `.statusbar`（`editor.php:51`）。放在最後一條分隔線之後，因為宿主用 `.sep:nth-of-type` 依序藏分隔線。
- **100%＝1 CSS px＝15 twips。**
- 等級：50、75、100、125、150、200。`+`、`−` 走到比目前百分比大或小的下一級。
- 開檔預設是現行的**符合寬度**（`min(可用寬度, 900)`），百分比照實算，不一定是整數級。按百分比回到符合寬度。
- 縮放時畫面中央對到的文件位置留在中央。
- 頁面比桌面寬時可以橫向捲動，左緣到得了；游標走到畫面外時橫向跟過去。
- 縮放不碰文件：不送任何編輯動作、版本不變、不算有修改。

**判準**：Chrome＋Firefox；真滑鼠、真鍵盤，走 CDP／WebDriver。

| 判準 | 內容 | 形式 |
|---|---|---|
| Z0 | 符合寬度下，`#paper` 寬、`canvas.width`、`docRows` 等於改動前的算式 | 一 |
| Z1 | 每一級：`#paper` 寬＝`round(頁寬 twips ÷ 15 × p ÷ 100)`，百分比標籤等於 p | 工具封閉（等級表由工具從頁面讀） |
| Z2 | 每一級：`canvas.width`＝`min(2400, round(css 寬 × dpr))`，且視窗內的 band 用這個寬度重畫過（不是 CSS 拉伸） | 一 |
| Z3 | 每一級：點同一個文件位置，引擎回報的游標都落在同一段的同一個偏移；橫向捲動後也一樣 | 一 |
| Z4 | 200%、窄視窗、長行尾端打字：游標在桌面可見範圍內 | 一 |
| Z5 | 每次縮放：中央的文件位置偏移不超過一行高 | 一 |
| Z6 | 200%、窄視窗：`scrollLeft`＝0 時 `#paper` 左緣在桌面內，`#paper` 寬不被 flex 壓縮 | 一 |
| Z7 | 縮放全程：引擎沒有收到編輯動作，版本不變，頁面不顯示有修改；存檔文字等於原文 | 一 |
| Z8 | 200%、長文件捲到尾端：視窗內的 band 都畫了 | 一 |
| Z9 | 宿主裡：三個控制項都可見、可按，放大確實生效 | 一 |

**紅案**（每條實作一個對應的突變，工具要轉紅）：拿掉橫向跟隨→Z4；拿掉中央保持→Z5；拿掉 `flex: none`→Z6；只改 CSS 寬不改 `canvas.width`→Z2。

**回歸**：`web/e2-editor-app.js` 變了要凍第 84 代，`web/e2-editor.html` 變了要重綁 `originalHtmlSha256`。第 84 代照第 83 代的作法重跑 F3、F4、V0′，結果要逐格等於第 83 代。

**一次性量測，不當閘門**：Chrome 上 200% 與符合寬度的打字 commit 時間各量一次，登錄在證據裡。發佈前 `boundaries` commit 門檻 16 ms 是 100% 附近量的，放大的成本沒量過。

**沒做的預設**：沒有縮放，瀏覽器自己的 Ctrl＋± 仍可用。

## 5. 具名限制

- **L-calc-zoom-not-done**：Calc 沒有縮放。
- **L-sheet-first-visit-from-a1**：第一次看的表一律從 A1，不讀檔案裡存的游標與捲動位置。Collabora 會捲到該表的游標。
- **L-sheet-range-not-remembered**：只記作用儲存格，不記範圍選取。切回來是單一格。
- **L-sheet-view-not-persisted**：只活在這次開檔內，重開從第一張表頂端開始。
- **L-zoom-backing-cap**：`MAX_BACKING_WIDTH` 是 2400，高解析度螢幕上 150% 以上會略糊，不改上限。
- **L-zoom-not-persisted**：重開回到符合寬度。
- **L-zoom-browser-keys**：Ctrl＋滾輪與 Ctrl＋± 仍是瀏覽器縮放，不攔截。
- **L-zoom-fractional-fit**：符合寬度的百分比不是整數級，第一下 `+`、`−` 走到相鄰整數級，步幅不等。
