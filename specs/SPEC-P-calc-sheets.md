# SPEC-P-calc-sheets：看見工作表身分、參照別張表的資料

2026-11-06 擁有者從 0.2.58 手測後提的候選裡選 A（Ctrl+C＋跨表 UI）。被問到「看見工作表身分」指的是什麼時，擁有者回「請去查 Collabora 怎麼做」。Ctrl+C 另見 `SPEC-P-calc-copy.md`。本文件只准 append。判準（第 4 節）在任何會算進它的量測之前釘死。

## 1. 現況（2026-11-06）

- **頁面**：分頁顯示的是核心給的真實工作表名稱（`partName`），目前那張用白底、綠色底線加粗體標出；隱藏的表顯示成停用的分頁，並寫出原因。名稱方塊只收 `A1` 這種寫法（`/^([A-Z]+)([1-9][0-9]*)$/`）。輸入中點別的格子會先提交再移動（`selectAt` → `_commitNow`）；點分頁走 `showPart`，也會先提交。所以打 `=` 再點別張表，會把一個不完整的 `=` 寫進格子。〔已觀察，原始碼〕
- **Collabora**（`cool-26-04`，〔已觀察，原始碼〕）：
  - 分頁：目前那張用文件類型的主色填底並加深色框（`spreadsheet-tab-selected`）；受保護的表在分頁上帶鎖頭圖示（`spreadsheet-tab-protected`，`Control.Tabs.js`）；有分頁顏色的表照文件的顏色畫；隱藏的表不畫分頁；雙擊分頁可改名。
  - 狀態列：核心給的 `.uno:StatusDocPos`（「第 N 張工作表，共 M 張」），另有選取的列數欄數、選取範圍的加總（`Control.StatusBar.js`）。
  - 名稱方塊：直接沿用核心的 `pos_window` 元件，輸入 `表名.A1` 由核心負責跳過去（`Control.AddressInputField.ts`）。
  - 跨表參照：輸入中點分頁只是 `setPart`，保留編輯中的內容、點格子插入參照，都由核心的輸入處理負責。這點是從原始碼推的，沒有實測〔推論〕。
- **核心**：`getPartInfo` 對每張表回報 `protected`（`docuno.cxx` `ScModelObj::getPartInfo`），而 SDK 開檔時已經逐張讀 `partInfo`，只取了 `visible`。〔已觀察，原始碼〕
- **E1**（`findings/evidence/calc-sheets/e1/`，原生 26.8，〔已觀察〕）：
  - `=$另一張表.A1`、`=另一張表.A1`、`='另一張表'.A1` 都算得出值。Excel 寫法 `=另一張表!A1` 回 `#NAME?`。
  - 核心的標準寫法只替需要的名稱加引號：`$'有 空白'.B1`、`$'2026'.B1`（打成 `$2026.B1` 也會被改成這樣）、`$'O''Neil'.B1`；`$Sheet_3.B1` 與 `$另一張表.A1` 不加。表名有空白或 `'` 卻沒加引號 → `Err:509`。
  - 表名比對不分大小寫（`$sheet_3.B1` → `$Sheet_3.B1`）。
  - 範圍寫成 `$'有 空白'.B1:B1`，表名只出現在第一段。

## 2. 決定（agent 依桌面 Calc／Collabora 的慣例定；不是難題，不送裁決）

1. **工作表身分＝Collabora 的三樣**：受保護的表在分頁上帶鎖頭（`aria-label` 與 `title` 寫「受保護的工作表」）；狀態列顯示「工作表 N／M」；名稱方塊接受帶表名的位址。目前分頁的標示維持現狀（已經跟其他分頁明顯不同）。隱藏的表維持停用的分頁並寫出原因，不改成 Collabora 那樣不畫（不拿掉現有的資訊）。
2. **名稱方塊**接受 `A1`、`$A$1`、`表名.A1`、`$表名.A1`、`'表 名'.A1`，也接受 Excel 寫法 `表名!A1`（這裡只是跳轉，沒有歧義）。表名不分大小寫。顯示仍然只寫 `A1`，與 Collabora、桌面相同。找不到表 → 提示且不動；隱藏的表 → 照現有的 `PART_HIDDEN` 訊息。
3. **點選參照（point mode）**：草稿以 `=` 開頭，而且游標停在可以插入參照的位置時：
   - 點格子插入它的位址；拖曳插入範圍。
   - 點別張表的分頁只切換畫面，不提交；之後點的格子寫成 `$表名.A1`（引號規則照 E1：只有單純名稱不加）。
   - Enter 或提交鈕會先回到原本那張表，再寫入原本那一格；Esc 回到原本那張表並取消輸入。
   - 「可以插入參照的位置」＝游標前（略過空白）是 `=`、`(`、`,`、`;`、`:`、`!`、`~` 或二元運算子 `+ - * / ^ & < >`；或者游標正好在上一次點選插入的參照後面（這時再點會換掉那個參照，跟桌面相同）。
   - 不在這些位置時，照現在的行為：點格子先提交再移動，點分頁先提交再切換。
4. **在別張表上時**，格內編輯器不顯示，編輯改在公式列繼續（游標位置不變），原本那張表的選取框不畫在別張表上。被點選的範圍畫一個虛線框。
5. **沒有引擎改動**：核心已經會算跨表公式（E1），`protected` 也已經從 `partInfo` 拿得到。照 v6 的引擎做，不連結。

## 3. 設計

- `spreadsheet-shell/calc-editor-session.js` 匯出三個純函式：`sheetReference(names, home, range)` 產生參照文字，`referenceSlot(text, start, end, last)` 判斷能不能插入、要換掉哪一段，`parseCellTarget(text, names)` 解析名稱方塊的輸入。session 加 `browsePart(part)`（不提交、不換作用格）與 `pointAt(x, y)`（唯讀的點選，不動作用格）。`_commitNow` 在別張表上時先 `viewer.showPart(home)`。
- `calc-document-sdk.js`：宣告 `part-info` 的引擎在開檔後逐張讀 `protected`，存成 `handle.partProtected`；讀不到就是 `null`（不畫鎖頭）。
- 頁面：分頁的鎖頭、`#sheet-position`、名稱方塊、點選參照、虛線框。
